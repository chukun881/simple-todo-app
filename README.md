# Simple Todo List App

A full-stack, multi-user todo app built as a learning project.

| Layer    | Tech                                   | Hosting |
|----------|----------------------------------------|---------|
| Frontend | Next.js (App Router, TypeScript), Tailwind CSS | Vercel  |
| Backend  | Python, Django, Django REST Framework  | Vercel (serverless Python) |
| Database | SQLite (local) / Postgres on Neon (production) | Neon |

## Repository layout

```
frontend/   Next.js app
backend/    Django REST API
```

Setup and deployment instructions are added as each part is built.
